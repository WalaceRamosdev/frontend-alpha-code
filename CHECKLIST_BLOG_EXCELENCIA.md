# 🎯 Checklist de Ouro: Padrão de Excelência Alpha Code para Blog Posts

Este documento serve como a **Bússola de SEO e Conversão** para todo conteúdo criado para a Alpha Code. Nenhum artigo deve ser publicado sem passar por este checklist.

---

## 🏗️ 1. Estrutura de Arquivo e Metadados (Frontmatter)

Todo arquivo `.md` deve começar com este bloco configurado:

```yaml
---
title: "Título Impactante com Palavra-Chave"
description: "Meta description de 140-160 caracteres com CTA e KW"
pubDate: 2026-02-02T18:00:00-03:00 # Sempre agendar para 18h
heroImage: "url-da-imagem"
author: "Equipe Alpha Code"
categories: ["Nicho", "Estratégia"]
tags: ["Tag 1", "Tag 2", "SEO"]
ctaType: "meio" # Opções: topo, meio, fundo
draft: false
---
```

---

## 🔍 2. SEO & Ranqueamento (Obrigatório)

- [ ] **Palavra-Chave Única:** Identifique a KW principal (ex: "site para psicólogos").
- [ ] **Distribuição da KW:**
    - Título (H1)
    - URL (slug curta e limpa)
    - Primeiros 100 caracteres do texto
    - Pelo menos um subtítulo H2
- [ ] **Introdução Direta:** Primeiros 3 parágrafos devem dizer: O Problema -> Para quem é -> O que vai aprender.
- [ ] **Staircase de H-Tags:** Use H2 para tópicos principais e H3 somente dentro de um H2. Nunca pule de H1 para H3.
- [ ] **Imagens Otimizadas:** Todo post deve ter `Alt Text` descritivo.
- [ ] **Conteúdo Denso:** Mínimo de 800 palavras. O Google ignora textos rasos.

---

## 🔗 3. Autoridade e Conectividade (O "Efeito Teia")

- [ ] **Links Internos (Min. 2):** Linkar para outro artigo do blog ou para a Home/Serviços da Alpha Code.
- [ ] **Links Externos (Min. 1):** Linkar para uma fonte oficial (Wikipedia, OAB, CFP, Google Blog, etc). Isso prova que nossa informação é verificável.
- [ ] **CTA Estratégico:** Todo post deve terminar com um convite à ação (Contato, outro post ou serviço).

---

## 💎 4. Estética de Leitura (Premium UX)

- [ ] **Parágrafos Curtos:** No máximo 3 a 4 linhas por parágrafo para facilitar a leitura no mobile.
- [ ] **Listas e Negritos:** Use `bullets` e **negrito** nas partes mais importantes para leitura escaneável.
- [ ] **Clareza de Proposta:** O artigo ajuda o leitor a tomar uma decisão? Se for apenas "encher linguiça", reescreva.

---

## 🚀 5. Ação Pós-Publicação

1. [ ] Validar se a URL está funcionando.
2. [ ] Testar os links internos e externos.
3. [ ] Passar a URL no **Google Search Console** para solicitar indexação.
4. [ ] Compartilhar nos "Canais Amigos" conforme o [GUIA_ACELERACAO_SEO.md](./GUIA_ACELERACAO_SEO.md).
