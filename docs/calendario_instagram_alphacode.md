# 📅 Planejamento Estratégico Instagram - Alpha Code

Este é o seu roteiro operacional para 30 dias de conteúdo. O objetivo é transformar seguidores em clientes através do equilíbrio entre atração, autoridade e vendas.

---

## 🧭 Pilares de Conteúdo
1. **Atração (Reels):** Trazer público novo com ganchos fortes.
2. **Educação (Carrossel):** Quebrar objeções e mostrar valor técnico.
3. **Conversão (Reels/Post):** Chamada direta para orçamento ou consultoria.

---

## 🗓️ Semana 1: Fundação e Consciência
*Foco: Mostrar que o problema (não ter site) custa dinheiro.*

- [ ] **Segunda (Reels) - Atração**
    - **Tema:** 3 sinais de que sua empresa precisa de um site urgente.
    - **Gancho:** "Seu negócio é invisível no Google?"
    - **Pontos:** Meta-dependência (só Instagram), informações repetidas no Direct, falta de presença nas buscas.
    - **CTA:** "Comente 'SITE' para uma análise gratuita."

- [ ] **Quarta (Carrossel) - Educação**
    - **Tema:** 5 Vantagens Inegociáveis de um Site Profissional.
    - **Slides:** Credibilidade 24h, SEO (Google), Automação de Leads, Design Premium, Canal de Vendas Próprio.
    - **CTA:** "Salve para não esquecer esses pilares."

- [ ] **Sexta (Reels) - Conversão**
    - **Tema:** Antes e Depois de uma Presença Online.
    - **Visual:** Comece com um perfil amador/link de bio ruim -> Mostre o site Alpha Code carregando em velocidade extrema.
    - **Legenda:** "O design certo converte curiosos em clientes."
    - **CTA:** "Link na bio para orçamentos."

---

## 🗓️ Semana 2: Autoridade e Comparação
*Foco: Posicionar a Alpha Code como a melhor escolha técnica.*

- [ ] **Segunda (Reels) - Atração**
    - **Tema:** "Quanto custa um site profissional?"
    - **Gancho:** "Não pergunte o preço, pergunte o retorno."
    - **Conteúdo:** Explique que um site é um ativo, não um gasto. Compare com o custo de perder um único cliente por falta de confiança.
    - **CTA:** "Me chama no direct para um orçamento personalizado."

- [ ] **Quarta (Carrossel) - Educação**
    - **Tema:** Instagram vs. Site: Quem ganha o jogo?
    - **Conclusão:** O Instagram é o aluguel, o Site é a sua casa própria. Você precisa dos dois trabalhando juntos.
    - **CTA:** "Você concorda? Deixe sua opinião nos comentários."

- [ ] **Sexta (Reels) - Conversão**
    - **Tema:** Por que sites Alpha Code vendem mais?
    - **Destaque:** Velocidade (Astro), SEO Nativo, Design que guia o olhar para o botão de compra.
    - **CTA:** "Quer escalar? Vamos construir seu sistema hoje."

---

## 🗓️ Semana 3: Prova Técnica e Conexão
*Foco: Mostrar os bastidores e a competência técnica.*

- [ ] **Segunda (Reels) - Atração**
    - **Tema:** 3 erros fatais que matam a conversão do seu site.
    - **Conteúdo:** Lentidão, botões que não funcionam no celular, textos difíceis de ler.
    - **CTA:** "O seu site tem algum desses? Eu te ajudo a corrigir."

- [ ] **Quarta (Carrossel) - Educação**
    - **Tema:** Checklist do Site de Elite.
    - **Checklist:** Responsividade total, Carregamento < 2s, Certificado SSL, Formulários Inteligentes, Pixel de Rastreamento.
    - **CTA:** "Envie este post para um empresário parceiro."

- [ ] **Sexta (Reels) - Conversão**
    - **Tema:** POV: Criando o próximo site top 1% do mercado.
    - **Vídeo:** Gravação acelerada (time-lapse) do código ou design sendo montado.
    - **Legenda:** "Aqui a gente não usa templates prontos. Construímos soluções exclusivas."
    - **CTA:** "Direct aberto para novos projetos."

---

## 🗓️ Semana 4: Escala e Fechamento
*Foco: Urgência e nichos específicos.*

- [ ] **Segunda (Reels) - Atração**
    - **Tema:** "Seu concorrente já tem um site melhor que o seu?"
    - **Gancho:** Desperte a urgência de não ficar para trás.
    - **CTA:** "Recupere o tempo perdido. Mande uma mensagem."

- [ ] **Quarta (Carrossel) - Conversão**
    - **Tema:** 5 Nichos que precisam de sistema próprio hoje.
    - **Lista:** Clínicas, Advogados, Restaurantes (Delivery sem taxas), Imobiliárias, Experts/Cursos.
    - **CTA:** "Seu nicho está aqui? Digite qual é abaixo."

- [ ] **Sexta (Reels) - Conversão**
    - **Tema:** Quanto o seu negócio pode crescer com a infraestrutura certa?
    - **Conteúdo:** Mostre um dashboard de crescimento ou uma simulação de vendas.
    - **Final:** "Encerre o mês com a decisão certa. Vamos fechar seu projeto?"

## 🚀 Check-list de Upload (Padrão Alpha Code)

1. **Gancho (Hook):** Os primeiros 3 segundos definem o sucesso. Use legendas grandes no vídeo.
2. **Qualidade Visual:** Use luz natural ou ring light. Captura de tela do site deve ser em alta resolução.
3. **Legenda:** Sempre comece com uma frase de impacto e termine com uma pergunta ou direção clara (CTA).
4. **Hashtags Estratégicas:**
   - `#siteprofissional` `#criacaodesites` `#marketingdigital` `#tecnologia` `#vendasoline` `#alphacode`
